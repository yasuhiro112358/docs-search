Privacy Policy

This privacy policy explains how the "Docs Search" extension handles user data.

Data Collection and Use

This extension uses the search queries provided by users to send to Google Search for displaying results. This data is transmitted externally, but is not stored by the extension.

Data Storage

The search options selected by the user (state of checkboxes) are saved in Google Chrome's local storage. This allows the user's settings to be maintained for the next use of the extension.

Sharing Data with Third Parties

The search queries generated by the user are sent to Google, which provides the search service. However, this only occurs when the user clicks the search button.

User Rights

Users have the right to access, correct, and delete their own data. If a user wishes to access or correct their data, they can do so from the extension's settings page.

Security

This extension takes appropriate technical measures to protect user data.

Changes to the Privacy Policy

The contents of this policy may be changed without prior notice for improvement. If there are significant changes, users will be notified.
